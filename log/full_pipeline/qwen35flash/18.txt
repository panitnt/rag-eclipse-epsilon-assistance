// delete all scalar nodes named "role"
delete s_role.all;

**Key Points:**

1. **Root Node Type**: The root is a **mapping node** (not a list) because the YAML has key-value pairs (`fleetSummary:` and `vehicles:`) at the top level. This is set using `YAMLDoc.setRootAsMap()`.

2. **Node Types Used**:
   - `MappingNode` - for objects with key-value pairs (fleetSummary, vehicles, location, engine, diagnostics, sensorReadings, maintenanceHistory entries)
   - `ScalarNode` - for simple values (strings, numbers, null)
   - `ListNode` - for arrays/lists (vehicles list, maintenanceHistory lists)

3. **Pattern Followed**: The code follows the exact patterns from the documentation:
   - `YAMLDoc.setRootAsMap()` to set root type
   - `YAMLDoc.getRoot()` to get the root node
   - `new MappingNode("name")` / `new ScalarNode("name", value)` / `new ListNode("name", count)`
   - `.value.appendNode()` to add child nodes
   - `.value.at(index)` to access list items

4. **Note on Null Values**: For the `location: null` case in vehicle 4, I used `new ScalarNode("location", null)` as shown in the documentation pattern for scalar nodes.
