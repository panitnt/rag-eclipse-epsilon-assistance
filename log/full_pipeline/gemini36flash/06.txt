How do you write an EGL template that mixes auto-generated content with hand-written code without it being overwritten on re-run?

Answer:

── ANSWER ────────────────────────────────────────────────
To mix auto-generated content with hand-written code without it being overwritten on re-run, you use **protected regions**.

Within an EGL template, protected regions are defined using the `preserve(String, String, String, Boolean, String)` method on the `out` built-in variable. The parameters for this method specify:

1. The starting comment delimiter for the target language
2. The ending comment delimiter for the target language
3. The name of the protected region
4. The enable-state (a Boolean)
5. The content of the protected region

When the template is executed, EGL's merge engine examines the target output destination. If a protected region is active (`On`) in both the generated output and the existing target file, the engine preserves the existing hand-written content rather than overwriting it. 

Note that while the documentation describes the `out.preserve(...)` method parameters and merge behavior, it does not include an explicit code example demonstrating the method's exact syntax within a template.
