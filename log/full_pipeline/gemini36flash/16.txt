To create the provided YAML document programmatically from scratch using Epsilon's EMC YAML Driver, we first determine the root node type:

The target YAML structure:
```yaml
book:
  title: The Quiet Harbour
  author: Elena Marsh
  yearPublished: 2019
```
Since the root of this document is a key-value mapping (containing the key `book`), the root must be initialized as a **mapping node** using `YAMLDoc.setRootAsMap()`.

### EOL Code Example

```eol
// Set the root of the YAML document as a mapping node
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

// Create the 'book' mapping node
var bookNode = new MappingNode("book");

// Create scalar nodes for title, author, and yearPublished
var titleNode = new ScalarNode("title", "The Quiet Harbour");
var authorNode = new ScalarNode("author", "Elena Marsh");
var yearPublishedNode = new ScalarNode("yearPublished", 2019);

// Append the scalar nodes into the 'book' mapping node
bookNode.value.appendNode(titleNode);
bookNode.value.appendNode(authorNode);
bookNode.value.appendNode(yearPublishedNode);

// Append the 'book' mapping node to the root
root.value.appendNode(bookNode);
```

---

* **Node Creation:** `MappingNode` and `ScalarNode` instances are constructed with key and value parameters.
* **Child Appending:** Calling `.value.appendNode(...)` appends nested nodes to a `MappingNode`.
