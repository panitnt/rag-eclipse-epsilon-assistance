### How do I set the root node of a YAML document?

The `root` property can be used for setting the root node of a YAML document. The root node of a YAML document can either be a mapping node or a list node. The `setRootAsMap()` function can be used for setting the root node into a mapping node. The `setRootAsList()` function can be used for setting the root node into a list node.

Based on the provided documentation, here is how to programmatically construct the YAML document from scratch.

### Root Node Analysis
The provided YAML document has a top-level key (`students`) that contains a sequence/list of student mapping elements. Therefore, the **root node is a mapping node**. To set up the document root, we call `YAMLDoc.setRootAsMap()`.

---

### EOL Code Example

```eol
// Set the document root as a mapping node
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

// Create a ListNode named "students" with 4 entries
var studentsNode = new ListNode("students", 4);

// First student: S001
var idNode1 = new ScalarNode("id", "S001");
var nameNode1 = new ScalarNode("name", "Grace Adeyemi");
var gradeNode1 = new ScalarNode("grade", "A");
studentsNode.value.at(0).appendNode(idNode1);
studentsNode.value.at(0).appendNode(nameNode1);
studentsNode.value.at(0).appendNode(gradeNode1);

// Second student: S002
var idNode2 = new ScalarNode("id", "S002");
var nameNode2 = new ScalarNode("name", "Tom Fielding");
var gradeNode2 = new ScalarNode("grade", "B");
studentsNode.value.at(1).appendNode(idNode2);
studentsNode.value.at(1).appendNode(nameNode2);
studentsNode.value.at(1).appendNode(gradeNode2);

// Third student: S003
var idNode3 = new ScalarNode("id", "S003");
var nameNode3 = new ScalarNode("name", "Priya Nair");
var gradeNode3 = new ScalarNode("grade", "A-");
studentsNode.value.at(2).appendNode(idNode3);
studentsNode.value.at(2).appendNode(nameNode3);
studentsNode.value.at(2).appendNode(gradeNode3);

// Fourth student: S004
var idNode4 = new ScalarNode("id", "S004");
var nameNode4 = new ScalarNode("name", "Ollie Bennett");
var gradeNode4 = new ScalarNode("grade", "C+");
studentsNode.value.at(3).appendNode(idNode4);
studentsNode.value.at(3).appendNode(nameNode4);
studentsNode.value.at(3).appendNode(gradeNode4);

// Append the students ListNode to the root mapping node
root.value.appendNode(studentsNode);
```

### Explicit Notes & Uncertainties
* **Supported Patterns Used:**
  * Setting the root via `setRootAsMap()` and accessing it with `YAMLDoc.getRoot()`.
  * Creating `ListNode` specifying name and count: `new ListNode("students", 4)`.
  * Accessing list item rows using `.value.at(index)` and populating them with `.appendNode(...)`.
  * Creating `ScalarNode` key-value pairs: `new ScalarNode("key", "value")`.
* **Uncertainty Flag:** The documentation explicitly states that `setRootAsMap()` sets a mapping root node, but the code examples in the context only illustrate `setRootAsList()`. Appending to `root.value` (`root.value.appendNode(studentsNode)`) follows the documented behavior for `MappingNode.value.appendNode(...)`.
