## Querying/modifying YAML documents in EOL
 
The YAML driver uses predefined naming conventions to allow developers to programmatically access and modify YAML documents in a concise way. A type of YAML node must be specified when accessing YAML nodes via the YAML driver. There are 3 types of nodes in YAML:

- `Scalar Node`. Scalar nodes are used to represent a single scalar value (e.g., string, boolean, integer). In the YAML driver, a scalar node consists of a key-value pair, in which the key represents the name of the scalar node, and the value represents the scalar value.
- `Mapping Node`. Mapping nodes are used to represent unordered collections of key-value pairs. In the YAML driver, a mapping node consists of a key-value pair, in which the key represents the name of the mapping node, and the value holds an unordered collection of key-value pairs, which in turn represent other nodes.
- `List (Sequence) Node`. List nodes are used to represent an ordered list of nodes or scalar values. In the YAML driver, a list node consists of a key-value pair, in which the key represents the name of the list node, and the value represents a list of nodes or scalar values.

This section outlines the supported conventions in the form of questions and answers followed by relevant examples.

── ANSWER ────────────────────────────────────────────────
Root type
- Your YAML has a single top-level mapping with key "device", so set the YAML document root as a mapping: YAMLDoc.setRootAsMap().
- For mapping nodes use .value.appendNode(child). (Use .appendNode(...) only for list-slot elements — not needed here.)

EOL script (complete, following the patterns in the documentation)
```eol
/* Set the root as a MappingNode and get it */
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

/* Create the 'device' mapping node and its scalar children */
var deviceNode = new MappingNode("device");

var idNode              = new ScalarNode("id", "DEV-2210");
var typeNode            = new ScalarNode("type", "thermostat");
var brandNode           = new ScalarNode("brand", "Nest");
var modelNode           = new ScalarNode("model", "Learning Thermostat v3");
var macNode             = new ScalarNode("mac", "AA:BB:CC:11:22:33");
var onlineNode          = new ScalarNode("online", true);
var firmwareNode        = new ScalarNode("firmwareVersion", "6.4.2");
var installedAtNode     = new ScalarNode("installedAt", "2023-11-02");
var roomNode            = new ScalarNode("room", "Living Room");
var warrantyExpiryNode  = new ScalarNode("warrantyExpiry", "2025-11-02");

/* Append the scalar nodes into the device mapping */
deviceNode.value.appendNode(idNode);
deviceNode.value.appendNode(typeNode);
deviceNode.value.appendNode(brandNode);
deviceNode.value.appendNode(modelNode);
deviceNode.value.appendNode(macNode);
deviceNode.value.appendNode(onlineNode);
deviceNode.value.appendNode(firmwareNode);
deviceNode.value.appendNode(installedAtNode);
deviceNode.value.appendNode(roomNode);
deviceNode.value.appendNode(warrantyExpiryNode);

/* Append the 'device' mapping to the document root */
root.value.appendNode(deviceNode);
```
