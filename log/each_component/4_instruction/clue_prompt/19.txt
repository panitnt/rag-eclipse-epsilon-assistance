Answer:

── ANSWER ────────────────────────────────────────────────
You should treat the document root as a mapping (the top-level node is the mapping with key "departments"). Use YAMLDoc.setRootAsMap() and append the top-level mapping entries with root.value.appendNode(...). For list slots use .value.at(i).appendNode(...) as shown in the YAML EMC examples.

Below is a complete EOL script that builds your YAML from scratch (it follows the exact patterns from the YAML EMC examples in the docs):

EOL script (create-departments.eol)
```eol
// Make the document root a mapping (top-level mapping)
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

// Create a 'departments' list with one department entry
var departmentsNode = new ListNode("departments", 1);

// For the first (and only) department entry, add name = "IT"
var deptName = new ScalarNode("name", "IT");
departmentsNode.value.at(0).appendNode(deptName);

// Create the 'teams' list inside the department with two team entries
var teamsNode = new ListNode("teams", 2);
teamsNode.value.at(0).appendNode(new ScalarNode("name", "Backend"));
teamsNode.value.at(1).appendNode(new ScalarNode("name", "Frontend"));

// Append the teams list to the department mapping (the first list slot)
departmentsNode.value.at(0).appendNode(teamsNode);

// Append the top-level 'departments' list to the root mapping
root.value.appendNode(departmentsNode);
```

How to run this EOL against a YamlModel
Use the same loading/execution pattern shown in the docs. Example Java runner (follow the exact pattern from the documentation):

model.setFile(new File("output.yaml"));

Notes and important points
- Root choice: because your top-level document is a mapping (key "departments"), use YAMLDoc.setRootAsMap().
- Appending: for mapping root entries use root.value.appendNode(...). For elements inside a ListNode use departmentsNode.value.at(i).appendNode(...), as in the examples.
- The example uses only APIs and patterns present in the provided documentation. The docs do not demonstrate an explicit save/write method for persisting the model to disk — you may need to call whatever persistence method the YAML driver exposes (not shown in the provided docs).
