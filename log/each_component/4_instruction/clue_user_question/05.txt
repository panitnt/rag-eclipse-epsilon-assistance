## Querying/modifying YAML documents in EOL
 
The YAML driver uses predefined naming conventions to allow developers to programmatically access and modify YAML documents in a concise way. A type of YAML node must be specified when accessing YAML nodes via the YAML driver. There are 3 types of nodes in YAML:

- `Scalar Node`. Scalar nodes are used to represent a single scalar value (e.g., string, boolean, integer). In the YAML driver, a scalar node consists of a key-value pair, in which the key represents the name of the scalar node, and the value represents the scalar value.
- `Mapping Node`. Mapping nodes are used to represent unordered collections of key-value pairs. In the YAML driver, a mapping node consists of a key-value pair, in which the key represents the name of the mapping node, and the value holds an unordered collection of key-value pairs, which in turn represent other nodes.
- `List (Sequence) Node`. List nodes are used to represent an ordered list of nodes or scalar values. In the YAML driver, a list node consists of a key-value pair, in which the key represents the name of the list node, and the value represents a list of nodes or scalar values.

The top-level YAML you gave is a mapping (root has a "dashboard" key whose value is a mapping). So set the root as a map with YAMLDoc.setRootAsMap(), create a MappingNode for "dashboard", create ScalarNode instances for each metric, append those scalar nodes into the dashboard mapping with .value.appendNode(...), and finally append the dashboard mapping into the root mapping with root.value.appendNode(...).

Complete EOL example (runnable, follows the patterns from the documentation):

```eol
// set the document root as a mapping
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

// create the "dashboard" mapping node
var dashboardNode = new MappingNode("dashboard");

// create scalar nodes for each dashboard metric
var activeUsersNode = new ScalarNode("activeUsers", 1204);
var newSignupsNode = new ScalarNode("newSignups", 38);
var churnRateNode = new ScalarNode("churnRate", 0.021);
var avgSessionMinutesNode = new ScalarNode("avgSessionMinutes", 14.6);
var supportTicketsOpenNode = new ScalarNode("supportTicketsOpen", 9);
var revenueTodayGBPNode = new ScalarNode("revenueTodayGBP", 18420.50);
var serverUptimePctNode = new ScalarNode("serverUptimePct", 99.98);
var errorRateLast1hNode = new ScalarNode("errorRateLast1h", 0.003);

// append the scalar nodes into the dashboard mapping (use .value.appendNode for mapping nodes)
dashboardNode.value.appendNode(activeUsersNode);
dashboardNode.value.appendNode(newSignupsNode);
dashboardNode.value.appendNode(churnRateNode);
dashboardNode.value.appendNode(avgSessionMinutesNode);
dashboardNode.value.appendNode(supportTicketsOpenNode);
dashboardNode.value.appendNode(revenueTodayGBPNode);
dashboardNode.value.appendNode(serverUptimePctNode);
dashboardNode.value.appendNode(errorRateLast1hNode);

// append the dashboard mapping into the document root (root is a mapping, so use root.value.appendNode)
root.value.appendNode(dashboardNode);
```

Notes:
- Because the top-level document is a mapping, we used YAMLDoc.setRootAsMap() and root.value.appendNode(...).
- For mapping nodes you must use .value.appendNode(...) to add child nodes (as shown above). For list nodes (not used here) you would populate individual list slots with .appendNode(...) on those slots.
