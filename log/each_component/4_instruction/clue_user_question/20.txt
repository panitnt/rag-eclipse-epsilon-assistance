### How do I set the root node of a YAML document?

The `root` property can be used for setting the root node of a YAML document. The root node of a YAML document can either be a mapping node or a list node. The `setRootAsMap()` function can be used for setting the root node into a mapping node. The `setRootAsList()` function can be used for setting the root node into a list node.

## Querying/modifying YAML documents in EOL
 
The YAML driver uses predefined naming conventions to allow developers to programmatically access and modify YAML documents in a concise way. A type of YAML node must be specified when accessing YAML nodes via the YAML driver. There are 3 types of nodes in YAML:

- `Scalar Node`. Scalar nodes are used to represent a single scalar value (e.g., string, boolean, integer). In the YAML driver, a scalar node consists of a key-value pair, in which the key represents the name of the scalar node, and the value represents the scalar value.
- `Mapping Node`. Mapping nodes are used to represent unordered collections of key-value pairs. In the YAML driver, a mapping node consists of a key-value pair, in which the key represents the name of the mapping node, and the value holds an unordered collection of key-value pairs, which in turn represent other nodes.
- `List (Sequence) Node`. List nodes are used to represent an ordered list of nodes or scalar values. In the YAML driver, a list node consists of a key-value pair, in which the key represents the name of the list node, and the value represents a list of nodes or scalar values.

Root node
- The top-level document begins with the mapping key "departments", so the document root is a Mapping node. Use YAMLDoc.setRootAsMap() and then append a ListNode named "departments" to the root's value.

Runnable EOL example (follows the API and patterns shown in the documentation)
- This builds the exact YAML structure you provided from scratch.

```eol
/* Set root as a Mapping node and get it */
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

/* Create the departments list (2 departments) */
var departmentsNode = new ListNode("departments", 2);

/* --- First department: Prepress --- */
/* Add the department name to the first list slot (a mapping node) */
departmentsNode.value.at(0).appendNode(new ScalarNode("name", "Prepress"));

/* Create teams list for the first department (2 teams) */
var teamsNode1 = new ListNode("teams", 2);

/* Team 1: Artwork */
teamsNode1.value.at(0).appendNode(new ScalarNode("name", "Artwork"));
var members1 = new ListNode("members", 2);
members1.value = Sequence{"Alice", "Bob"};            // sequence of scalars
teamsNode1.value.at(0).appendNode(members1);

/* Team 2: Plate Making */
teamsNode1.value.at(1).appendNode(new ScalarNode("name", "Plate Making"));
var members2 = new ListNode("members", 2);
members2.value = Sequence{"Charlie", "Diana"};
teamsNode1.value.at(1).appendNode(members2);

/* Attach teams to first department */
departmentsNode.value.at(0).appendNode(teamsNode1);

/* --- Second department: Production --- */
departmentsNode.value.at(1).appendNode(new ScalarNode("name", "Production"));

/* Create teams list for the second department (1 team) */
var teamsNode2 = new ListNode("teams", 1);

/* Attach teams to second department */

root.value.appendNode(departmentsNode);
```

Notes and mapping to the documentation patterns
- Root is set with YAMLDoc.setRootAsMap() because the top-level is a mapping containing the "departments" key.
- For MappingNode children (including the root mapping), use .value.appendNode(...) — shown above when attaching the departments list to root and when adding "country" etc. in the docs.
- For ListNode slots, use .value.at(index).appendNode(...) to add child Mapping/MappingNode entries into each list slot — as used for projects in the docs.
- For lists of scalar values (members), use a ListNode and assign its .value to Sequence{...} (as shown for the industry example in the docs).
