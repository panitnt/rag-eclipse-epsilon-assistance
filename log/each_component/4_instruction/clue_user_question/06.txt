## Querying/modifying YAML documents in EOL
 
The YAML driver uses predefined naming conventions to allow developers to programmatically access and modify YAML documents in a concise way. A type of YAML node must be specified when accessing YAML nodes via the YAML driver. There are 3 types of nodes in YAML:

- `Scalar Node`. Scalar nodes are used to represent a single scalar value (e.g., string, boolean, integer). In the YAML driver, a scalar node consists of a key-value pair, in which the key represents the name of the scalar node, and the value represents the scalar value.
- `Mapping Node`. Mapping nodes are used to represent unordered collections of key-value pairs. In the YAML driver, a mapping node consists of a key-value pair, in which the key represents the name of the mapping node, and the value holds an unordered collection of key-value pairs, which in turn represent other nodes.
- `List (Sequence) Node`. List nodes are used to represent an ordered list of nodes or scalar values. In the YAML driver, a list node consists of a key-value pair, in which the key represents the name of the list node, and the value represents a list of nodes or scalar values.

The top-level of your YAML is a mapping with a single key "students" whose value is a sequence (list). So set the document root as a mapping, create a ListNode named "students" with 4 entries, fill each list-slot (mapping) with scalar nodes, and append the list node into the root mapping.

Complete EOL script (runnable in an Epsilon environment that provides YAMLDoc):

```eol
// Set root to a mapping node
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

// Create a list node "students" with 4 entries
var studentsNode = new ListNode("students", 4);

// Student 1
var s1_id = new ScalarNode("id", "S001");
var s1_name = new ScalarNode("name", "Grace Adeyemi");
var s1_grade = new ScalarNode("grade", "A");
studentsNode.value.at(0).appendNode(s1_id);
studentsNode.value.at(0).appendNode(s1_name);
studentsNode.value.at(0).appendNode(s1_grade);

// Student 2
var s2_id = new ScalarNode("id", "S002");
var s2_name = new ScalarNode("name", "Tom Fielding");
var s2_grade = new ScalarNode("grade", "B");
studentsNode.value.at(1).appendNode(s2_id);
studentsNode.value.at(1).appendNode(s2_name);
studentsNode.value.at(1).appendNode(s2_grade);

// Student 3
var s3_id = new ScalarNode("id", "S003");
var s3_name = new ScalarNode("name", "Priya Nair");
var s3_grade = new ScalarNode("grade", "A-");
studentsNode.value.at(2).appendNode(s3_id);
studentsNode.value.at(2).appendNode(s3_name);
studentsNode.value.at(2).appendNode(s3_grade);

// Student 4
var s4_id = new ScalarNode("id", "S004");
var s4_name = new ScalarNode("name", "Ollie Bennett");
var s4_grade = new ScalarNode("grade", "C+");
studentsNode.value.at(3).appendNode(s4_id);
studentsNode.value.at(3).appendNode(s4_name);
```

Notes:
- Root is a mapping, so use root.value.appendNode(...) to add the students list node.
- The list node slots are accessed with studentsNode.value.at(index) and you add entries there with .appendNode(...), as shown.
