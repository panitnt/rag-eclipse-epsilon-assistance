## Querying/modifying YAML documents in EOL
 
The YAML driver uses predefined naming conventions to allow developers to programmatically access and modify YAML documents in a concise way. A type of YAML node must be specified when accessing YAML nodes via the YAML driver. There are 3 types of nodes in YAML:

- `Scalar Node`. Scalar nodes are used to represent a single scalar value (e.g., string, boolean, integer). In the YAML driver, a scalar node consists of a key-value pair, in which the key represents the name of the scalar node, and the value represents the scalar value.
- `Mapping Node`. Mapping nodes are used to represent unordered collections of key-value pairs. In the YAML driver, a mapping node consists of a key-value pair, in which the key represents the name of the mapping node, and the value holds an unordered collection of key-value pairs, which in turn represent other nodes.
- `List (Sequence) Node`. List nodes are used to represent an ordered list of nodes or scalar values. In the YAML driver, a list node consists of a key-value pair, in which the key represents the name of the list node, and the value represents a list of nodes or scalar values.

The root of your YAML document is a mapping (it contains named keys: server, database, allowedOrigins, rateLimits), so use setRootAsMap() and append top-level nodes with root.value.appendNode(...). For mapping children use mappingNode.value.appendNode(...). For a list of scalars use ListNode.value = Sequence{...}. For a list of mappings (rateLimits) create a ListNode with the required size and populate each slot with .value.at(i).appendNode(...).

Complete EOL example that builds your YAML from scratch:

```eol
// Set root as a mapping
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

// server mapping
var serverNode = new MappingNode("server");
var serverHost = new ScalarNode("host", "0.0.0.0");
var serverPort = new ScalarNode("port", 8443);
var serverProtocol = new ScalarNode("protocol", "https");
var serverMaxConnections = new ScalarNode("maxConnections", 500);
serverNode.value.appendNode(serverHost);
serverNode.value.appendNode(serverPort);
serverNode.value.appendNode(serverProtocol);
serverNode.value.appendNode(serverMaxConnections);

// database mapping
var databaseNode = new MappingNode("database");
var dbEngine = new ScalarNode("engine", "postgresql");
var dbHost = new ScalarNode("host", "db01.internal");
var dbPort = new ScalarNode("port", 5432);
var dbPoolSize = new ScalarNode("poolSize", 20);
databaseNode.value.appendNode(dbEngine);
databaseNode.value.appendNode(dbHost);
databaseNode.value.appendNode(dbPort);
databaseNode.value.appendNode(dbPoolSize);

// allowedOrigins: list of scalars
var allowedOriginsNode = new ListNode("allowedOrigins", 3);
allowedOriginsNode.value = Sequence{
    "https://app.example.com",
    "https://admin.example.com",
    "https://staging.example.com"
};

// rateLimits: list of mappings
var rateLimitsNode = new ListNode("rateLimits", 2);

// first rate limit (slot 0)
var rl1_tier = new ScalarNode("tier", "free");
var rl1_requests = new ScalarNode("requestsPerMinute", 60);
rateLimitsNode.value.at(0).appendNode(rl1_tier);
rateLimitsNode.value.at(0).appendNode(rl1_requests);

// second rate limit (slot 1)
var rl2_tier = new ScalarNode("tier", "pro");
var rl2_requests = new ScalarNode("requestsPerMinute", 600);
rateLimitsNode.value.at(1).appendNode(rl2_tier);
rateLimitsNode.value.at(1).appendNode(rl2_requests);

// append top-level nodes to the root mapping
root.value.appendNode(serverNode);
root.value.appendNode(databaseNode);
root.value.appendNode(allowedOriginsNode);
root.value.appendNode(rateLimitsNode);
```

This follows the EMC YAML Driver patterns shown in the documentation:
- setRootAsMap() for a mapping root,
- root.value.appendNode(...) for top-level mapping entries,
- mappingNode.value.appendNode(...) for mapping children,
- ListNode.value = Sequence{...} for sequences of scalars, and
- listNode.value.at(i).appendNode(...) to populate list slots that hold mappings.
