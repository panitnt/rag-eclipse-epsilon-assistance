### How do I set the root node of a YAML document?

The `root` property can be used for setting the root node of a YAML document. The root node of a YAML document can either be a mapping node or a list node. The `setRootAsMap()` function can be used for setting the root node into a mapping node. The `setRootAsList()` function can be used for setting the root node into a list node.

── ANSWER ────────────────────────────────────────────────
Root node
- Your YAML document is a mapping whose single top-level key is "dashboard". So you should set the YAML root as a mapping (setRootAsMap()).

Runnable EOL example
- This EOL script follows the same API and patterns shown in the documentation examples (new MappingNode, new ScalarNode, setRootAsMap, getRoot, .value.appendNode).

```eol
/* Set the document root to a mapping node and get it */
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

/* Create the dashboard mapping node */
var dashboardNode = new MappingNode("dashboard");

/* Add the scalar properties to the dashboard mapping */
dashboardNode.value.appendNode(new ScalarNode("activeUsers", 1204));
dashboardNode.value.appendNode(new ScalarNode("newSignups", 38));
dashboardNode.value.appendNode(new ScalarNode("churnRate", 0.021));
dashboardNode.value.appendNode(new ScalarNode("avgSessionMinutes", 14.6));
dashboardNode.value.appendNode(new ScalarNode("supportTicketsOpen", 9));
dashboardNode.value.appendNode(new ScalarNode("revenueTodayGBP", 18420.50));
dashboardNode.value.appendNode(new ScalarNode("serverUptimePct", 99.98));
dashboardNode.value.appendNode(new ScalarNode("errorRateLast1h", 0.003));

/* Append the dashboard mapping to the document root */
root.value.appendNode(dashboardNode);
```

Notes and small caveat
- The examples in the documentation show both forms of appending nodes in different contexts (e.g. mappingNode.value.appendNode(...) and some nodes using appendNode(...) directly). In this example I used root.value.appendNode(...) because the documentation explicitly demonstrates using .value.appendNode(...) for mapping nodes. If your runtime exposes appendNode directly on the root mapping object (root.appendNode(...)), that is also consistent with the examples and should work as well.
