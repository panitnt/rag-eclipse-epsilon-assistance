## Querying/modifying YAML documents in EOL
 
The YAML driver uses predefined naming conventions to allow developers to programmatically access and modify YAML documents in a concise way. A type of YAML node must be specified when accessing YAML nodes via the YAML driver. There are 3 types of nodes in YAML:

- `Scalar Node`. Scalar nodes are used to represent a single scalar value (e.g., string, boolean, integer). In the YAML driver, a scalar node consists of a key-value pair, in which the key represents the name of the scalar node, and the value represents the scalar value.
- `Mapping Node`. Mapping nodes are used to represent unordered collections of key-value pairs. In the YAML driver, a mapping node consists of a key-value pair, in which the key represents the name of the mapping node, and the value holds an unordered collection of key-value pairs, which in turn represent other nodes.
- `List (Sequence) Node`. List nodes are used to represent an ordered list of nodes or scalar values. In the YAML driver, a list node consists of a key-value pair, in which the key represents the name of the list node, and the value represents a list of nodes or scalar values.

```eol
// Root is a mapping because the YAML top-level is: departments: ...
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

// Create the departments sequence with 2 department entries
var departmentsNode = new ListNode("departments", 2);

// --- Department 1: Prepress ---
var dept1Name = new ScalarNode("name", "Prepress");

// teams list for Prepress (2 teams)
var dept1Teams = new ListNode("teams", 2);

// Team 1: Artwork
var team1Name = new ScalarNode("name", "Artwork");
var team1Members = new ListNode("members", 2);
team1Members.value = Sequence{"Alice", "Bob"};
dept1Teams.value.at(0).appendNode(team1Name);
dept1Teams.value.at(0).appendNode(team1Members);

// Team 2: Plate Making
var team2Name = new ScalarNode("name", "Plate Making");
var team2Members = new ListNode("members", 2);
team2Members.value = Sequence{"Charlie", "Diana"};
dept1Teams.value.at(1).appendNode(team2Name);
dept1Teams.value.at(1).appendNode(team2Members);

// Attach name and teams to department 1 entry
departmentsNode.value.at(0).appendNode(dept1Name);
departmentsNode.value.at(0).appendNode(dept1Teams);

// --- Department 2: Production ---
var dept2Name = new ScalarNode("name", "Production");

// teams list for Production (1 team)
var dept2Teams = new ListNode("teams", 1);

// Team: Printing
var team3Name = new ScalarNode("name", "Printing");
var team3Members = new ListNode("members", 2);
team3Members.value = Sequence{"Ethan", "Fiona"};
dept2Teams.value.at(0).appendNode(team3Name);
dept2Teams.value.at(0).appendNode(team3Members);

// Attach name and teams to department 2 entry

departmentsNode.value.at(1).appendNode(dept2Teams);
```
