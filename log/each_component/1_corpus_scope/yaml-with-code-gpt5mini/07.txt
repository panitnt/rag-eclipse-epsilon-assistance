## Querying/modifying YAML documents in EOL
 
The YAML driver uses predefined naming conventions to allow developers to programmatically access and modify YAML documents in a concise way. A type of YAML node must be specified when accessing YAML nodes via the YAML driver. There are 3 types of nodes in YAML:

- `Scalar Node`. Scalar nodes are used to represent a single scalar value (e.g., string, boolean, integer). In the YAML driver, a scalar node consists of a key-value pair, in which the key represents the name of the scalar node, and the value represents the scalar value.
- `Mapping Node`. Mapping nodes are used to represent unordered collections of key-value pairs. In the YAML driver, a mapping node consists of a key-value pair, in which the key represents the name of the mapping node, and the value holds an unordered collection of key-value pairs, which in turn represent other nodes.
- `List (Sequence) Node`. List nodes are used to represent an ordered list of nodes or scalar values. In the YAML driver, a list node consists of a key-value pair, in which the key represents the name of the list node, and the value represents a list of nodes or scalar values.

/**
	 * Creates a YAML node entry based on the given property and parameters.
	 * 
	 * @param yamlProperty the property describing the node type and name
	 * @param parameters the parameters used to create the node
	 * @return the created YAML node entry
	 */
	private static Entry getNode(YamlProperty yamlProperty, Collection<Object> parameters) {
		Map<String, Object> map = new LinkedHashMap<String, Object>();
		switch(yamlProperty.getType()) {
			case ScalarNode:
				return getScalarNode(yamlProperty, new ArrayList(parameters));
				
			case MappingNode:
				return getMappingNode(yamlProperty, new ArrayList(parameters));
				
			case ListNode:
				return getListNode(yamlProperty, new ArrayList(parameters));
		}
		return map.entrySet().iterator().next();	
	}

/**
	 * Finds the given YAML object within a mapping node.
	 * 
	 * @param mappingNode the mapping node to search
	 * @param yamlObject the YAML object to find
	 */
	private static void findYamlObject(Map mappingNode, YamlObject yamlObject) {
		Set<Entry> entries = (Set<Entry>) mappingNode.entrySet();	
		for (Entry entry: entries) {
			if (!yamlObject.isFound()) {
				if (entry.equals(yamlObject.getValue())) {
					yamlObject.setParentNode(mappingNode);
				}
				else {
					findYamlObject(entry.getValue(), yamlObject);
				}
			}
			else {
				break;
			}
		}
	}

/**
	 * Creates a scalar YAML node entry.
	 * 
	 * @param yamlProperty the property describing the node
	 * @param parameters the parameters used to create the node

	private static Entry getScalarNode(YamlProperty yamlProperty, List parameters) {
		Map<String, Object> map = new LinkedHashMap<String, Object>();

/**
	 * Creates a list YAML node entry.
	 * 
	 * @param yamlProperty the property describing the node
	 * @param parameters the parameters used to create the node
	 * @return the created list YAML node entry
	 */
	private static Entry getListNode(YamlProperty yamlProperty, List parameters) {
		Map<String, Object> map = new LinkedHashMap<String, Object>();
		String nodeName = getNameParameter(yamlProperty, parameters, YamlNodeType.ListNode);
		Object valueParameter = getValueParameter(yamlProperty, parameters);
		int listSize = (int) YamlTypeConverter.cast(valueParameter.toString(), YamlDataType.INTEGER);
		List list = new ArrayList<>();
		for(int i=0; i < listSize; i++) {
			list.add(new LinkedHashMap());
		}	
		map.put(nodeName, list);
		return map.entrySet().iterator().next();
	}

── ANSWER ────────────────────────────────────────────────
The top-level of your YAML document is a mapping (it has named keys: server, database, allowedOrigins, rateLimits). So you should set the document root as a mapping (use setRootAsMap()).

Below is a complete EOL script (following the patterns used in the YAML EMC examples) that creates the YAML document from scratch. It follows the same API usage shown in the documentation: YAMLDoc.setRootAsMap(), YAMLDoc.getRoot(), new MappingNode(...), new ScalarNode(...), new ListNode(...), Sequence{...}, and appending child nodes into mapping/list nodes.

EOL script:

```eol
// Set the root to be a mapping (top-level mapping node)
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

// --- server mapping ---
var serverNode = new MappingNode("server");
var serverHost = new ScalarNode("host", "0.0.0.0");
var serverPort = new ScalarNode("port", 8443);
var serverProtocol = new ScalarNode("protocol", "https");
var serverMaxConnections = new ScalarNode("maxConnections", 500);

serverNode.value.appendNode(serverHost);
serverNode.value.appendNode(serverPort);
serverNode.value.appendNode(serverProtocol);
serverNode.value.appendNode(serverMaxConnections);

// --- database mapping ---
var databaseNode = new MappingNode("database");
var dbEngine = new ScalarNode("engine", "postgresql");
var dbHost = new ScalarNode("host", "db01.internal");
var dbPort = new ScalarNode("port", 5432);
var dbPoolSize = new ScalarNode("poolSize", 20);

databaseNode.value.appendNode(dbEngine);
databaseNode.value.appendNode(dbHost);
databaseNode.value.appendNode(dbPort);
databaseNode.value.appendNode(dbPoolSize);

// --- allowedOrigins sequence (simple scalar sequence) ---
var allowedOriginsNode = new ListNode("allowedOrigins", 3);
allowedOriginsNode.value = Sequence{
    "https://app.example.com",
    "https://admin.example.com",
    "https://staging.example.com"
};

// --- rateLimits sequence (sequence of mappings) ---
var rateLimitsNode = new ListNode("rateLimits", 2);

// first rate-limit mapping (list element 0)
var tier1 = new ScalarNode("tier", "free");
var rpm1 = new ScalarNode("requestsPerMinute", 60);
rateLimitsNode.value.at(0).appendNode(tier1);
rateLimitsNode.value.at(0).appendNode(rpm1);

// second rate-limit mapping (list element 1)
var tier2 = new ScalarNode("tier", "pro");
var rpm2 = new ScalarNode("requestsPerMinute", 600);
rateLimitsNode.value.at(1).appendNode(tier2);
rateLimitsNode.value.at(1).appendNode(rpm2);

// --- append top-level entries to the root mapping ---
root.value.appendNode(serverNode);
root.value.appendNode(databaseNode);
root.value.appendNode(allowedOriginsNode);
root.value.appendNode(rateLimitsNode);
```

- The documentation examples set the root as a list (setRootAsList()) — here we explicitly set the root as a mapping (setRootAsMap()) because your YAML is a top-level mapping.
