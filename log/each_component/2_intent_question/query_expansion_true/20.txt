### How do I set the root node of a YAML document?

The `root` property can be used for setting the root node of a YAML document. The root node of a YAML document can either be a mapping node or a list node. The `setRootAsMap()` function can be used for setting the root node into a mapping node. The `setRootAsList()` function can be used for setting the root node into a list node.

── ANSWER ────────────────────────────────────────────────
The top-level of your YAML is a mapping (it has the key "departments"), so set the document root as a mapping node (setRootAsMap()). Below is a complete EOL script (following the same API patterns shown in the docs) that builds your YAML from scratch.

EOL script:

YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

var departmentsNode = new ListNode("departments", 2);

// First department: Prepress
departmentsNode.value.at(0).appendNode(new ScalarNode("name", "Prepress"));

var teamsNode1 = new ListNode("teams", 2);
teamsNode1.value.at(0).appendNode(new ScalarNode("name", "Artwork"));
var membersA = new ListNode("members", 2);
membersA.value = Sequence{"Alice", "Bob"};
teamsNode1.value.at(0).appendNode(membersA);

teamsNode1.value.at(1).appendNode(new ScalarNode("name", "Plate Making"));
var membersB = new ListNode("members", 2);
membersB.value = Sequence{"Charlie", "Diana"};
teamsNode1.value.at(1).appendNode(membersB);

departmentsNode.value.at(0).appendNode(teamsNode1);

// Second department: Production
departmentsNode.value.at(1).appendNode(new ScalarNode("name", "Production"));

var teamsNode2 = new ListNode("teams", 1);
teamsNode2.value.at(0).appendNode(new ScalarNode("name", "Printing"));
var membersC = new ListNode("members", 2);
membersC.value = Sequence{"Ethan", "Fiona"};
teamsNode2.value.at(0).appendNode(membersC);

departmentsNode.value.at(1).appendNode(teamsNode2);

// Attach departments to the root mapping
root.appendNode(departmentsNode);
