## Querying/modifying YAML documents in EOL
 
The YAML driver uses predefined naming conventions to allow developers to programmatically access and modify YAML documents in a concise way. A type of YAML node must be specified when accessing YAML nodes via the YAML driver. There are 3 types of nodes in YAML:

- `Scalar Node`. Scalar nodes are used to represent a single scalar value (e.g., string, boolean, integer). In the YAML driver, a scalar node consists of a key-value pair, in which the key represents the name of the scalar node, and the value represents the scalar value.
- `Mapping Node`. Mapping nodes are used to represent unordered collections of key-value pairs. In the YAML driver, a mapping node consists of a key-value pair, in which the key represents the name of the mapping node, and the value holds an unordered collection of key-value pairs, which in turn represent other nodes.
- `List (Sequence) Node`. List nodes are used to represent an ordered list of nodes or scalar values. In the YAML driver, a list node consists of a key-value pair, in which the key represents the name of the list node, and the value represents a list of nodes or scalar values.

Question:
How can I create programmatically the YAML document I provided as input, from scratch using the EMC YAML Driver? First, you should figure out what is the root node, either a list node and mapping node, and change the code correspondingly.
departments:
  - name: IT
    teams:
      - name: Backend
      - name: Frontend

Answer:

── ANSWER ────────────────────────────────────────────────
The top-level of your YAML is a mapping (it has the single key "departments"). So set the YAML document root as a MappingNode and create a ListNode for "departments" whose first entry is a MappingNode that contains the "name" scalar and a "teams" ListNode.

Complete EOL (YAML EMC) script to create your document from scratch:

```eol
// Root is a mapping because the file starts with "departments: ..."
YAMLDoc.setRootAsMap();
var root = YAMLDoc.getRoot();

// Create the departments sequence with one entry (the IT department)
var departmentsNode = new ListNode("departments", 1);

// Create the department's name scalar
var deptName = new ScalarNode("name", "IT");

// Create the teams sequence with two entries
var teamsNode = new ListNode("teams", 2);
teamsNode.value.at(0).appendNode(new ScalarNode("name", "Backend"));
teamsNode.value.at(1).appendNode(new ScalarNode("name", "Frontend"));

// Populate the first (and only) department mapping entry
departmentsNode.value.at(0).appendNode(deptName);
departmentsNode.value.at(0).appendNode(teamsNode);

// Append the departments list to the root mapping
root.value.appendNode(departmentsNode);
```

If the YAML had been a top-level sequence (i.e., started with "- ..."), you would use YAMLDoc.setRootAsList() and then work with root.value.addRows(...) / root.value.at(i) like in the examples.
