## Querying/modifying YAML documents in EOL
 
The YAML driver uses predefined naming conventions to allow developers to programmatically access and modify YAML documents in a concise way. A type of YAML node must be specified when accessing YAML nodes via the YAML driver. There are 3 types of nodes in YAML:

- `Scalar Node`. Scalar nodes are used to represent a single scalar value (e.g., string, boolean, integer). In the YAML driver, a scalar node consists of a key-value pair, in which the key represents the name of the scalar node, and the value represents the scalar value.
- `Mapping Node`. Mapping nodes are used to represent unordered collections of key-value pairs. In the YAML driver, a mapping node consists of a key-value pair, in which the key represents the name of the mapping node, and the value holds an unordered collection of key-value pairs, which in turn represent other nodes.
- `List (Sequence) Node`. List nodes are used to represent an ordered list of nodes or scalar values. In the YAML driver, a list node consists of a key-value pair, in which the key represents the name of the list node, and the value represents a list of nodes or scalar values.

── ANSWER ────────────────────────────────────────────────
The top-level of your YAML is a mapping (it has a single key "book" whose value is a mapping). So the document root should be a MappingNode. The EOL code below follows the exact patterns shown in the documentation (new MappingNode, new ScalarNode, mappingNode.value.appendNode(...), and YAMLDoc.setRootAsMap()) and builds the YAML document in-memory.

Complete EOL example (runnable in an Epsilon script using the YAML EMC driver):

```eol
// Make the document root a mapping
YAMLDoc.setRootAsMap();

// Initialise the root mapping node
YAMLDoc.root.value = new MappingNode();

// Create the "book" mapping node and its scalar children
var bookNode = new MappingNode("book");
var titleNode = new ScalarNode("title", "The Quiet Harbour");
var authorNode = new ScalarNode("author", "Elena Marsh");
var yearNode = new ScalarNode("yearPublished", 2019);

// Append the scalar children to the book mapping
bookNode.value.appendNode(titleNode);
bookNode.value.appendNode(authorNode);
bookNode.value.appendNode(yearNode);

// Append the book mapping to the document root
YAMLDoc.root.value.appendNode(bookNode);
```

Notes:
- If your YAML had a top-level sequence (list) you would call YAMLDoc.setRootAsList() and use the ListNode patterns shown in the docs instead.
- The documentation examples show building the in-memory YAML structure but do not show how to persist (save) the YAML document to disk; the exact save/serialize call is not demonstrated in the provided documentation, so I have not included it here.
